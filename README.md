# Cozy Reader (WIP)

一款面向本地阅读的桌面应用。

旧版（v0.x.x）已迁移到 `Vue` 分支；当前新版基于 `Svelte 5 + SvelteKit + Tauri v2` 重新设计、开发。

## 支持格式

`✅` 当前支持　`🕓` 计划支持

| 格式           | 状态 | 说明         |
| -------------- | ---- | ------------ |
| `Markdown`     | ✅    | *无进度保存* |
| `HTML`         | ✅    | *无进度保存* |
| `TXT`          | 🕓    | *无进度保存* |
| `EPUB`         | 🕓    |              |
| `PDF`          | 🕓    |              |
| `MOBI`         | 🕓    |              |
| `AZW` / `AZW3` | 🕓    | 电子书格式   |
| `CBZ`          | 🕓    |              |
| `FB2` / `FBZ`  | 🕓    |              |
| `CBR`          | 🕓    |              |
